# Senior Frontend Engineer — Job Description

We are hiring a Senior Frontend Engineer to own our patient-facing web app
and design system.

## Requirements

- 5+ years frontend engineering
- Expert TypeScript and React (hooks, performance, state management)
- CSS architecture and design systems (Tailwind or equivalent)
- Accessibility (WCAG 2.1) as a first-class concern
- Testing: component + end-to-end (Playwright)
- Performance profiling and optimization (Core Web Vitals)

## Preferred

- GraphQL clients and caching
- Vite/webpack build tooling
- CI/CD and release automation
- Led or mentored engineers

## Responsibilities

- Own the frontend platform: design system, tooling, performance
- Raise and maintain Core Web Vitals scores
- Review code, mentor junior engineers
- Partner with design and product on UX quality
