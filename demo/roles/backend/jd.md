# Senior Backend Engineer — Job Description

We are hiring a Senior Backend Engineer to design and own the core services
behind our payments platform.

## Requirements

- 5+ years backend engineering in production
- Strong Python (FastAPI/Django) or Go
- Deep PostgreSQL experience: schema design, indexing, transactions
- Message queues in production (Kafka preferred)
- Distributed systems fundamentals: consistency, idempotency, retries
- Kubernetes and CI/CD
- Monitoring/observability (OpenTelemetry, Grafana)

## Preferred

- Payments/fintech domain experience
- ClickHouse or columnar stores
- Terraform and AWS
- Led or mentored engineers

## Responsibilities

- Own services from design to production
- Design for exactly-once semantics and failure recovery
- Improve reliability and performance of critical paths
- Review code, mentor junior engineers
