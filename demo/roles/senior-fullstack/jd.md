# Senior Full Stack Engineer — Job Description

We are hiring a Senior Full Stack Engineer to own customer-facing features
in our B2B analytics platform from design through production.

## Requirements

- 5+ years of professional full stack development
- Strong TypeScript and React (hooks, state management, performance)
- Strong backend experience: Node.js or Python, REST/GraphQL APIs
- PostgreSQL and Redis in production
- Experience with AWS (Lambda, RDS, S3) and Docker
- Testing: unit + integration + end-to-end
- Led or mentored other engineers

## Preferred

- WebSockets / real-time features
- Kubernetes and CI/CD ownership
- Observability tooling (OpenTelemetry, Grafana)
- Monorepo tooling (Turborepo/pnpm workspaces)

## Responsibilities

- Own features end to end: design, implement, ship, measure
- Improve frontend performance and accessibility
- Review code and mentor junior engineers
- Work with product on technical tradeoffs
